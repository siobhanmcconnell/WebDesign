# Reflection:

One thing I learned was how to create scale transforms. They're a fun way to add interactivity.

I tried to balance creativity with usability in the site's structure. I didn't want the content to just be listed out, so I had to figure out ways of organizing things that made the site interesting to look at, but still easy to navigate. I used flexbox and grid a lot to organize things in engaging ways. I also tried to be creative with the color palette. My goal was to use colors that were visually appealing on their own, but also use them to add visual hierarchy.

I'm most proud of my flexbox and grid layouts. I feel like I made those most progress over time with those and that's where I saw considerable improvement in my site's structure. It was also one of the more challenging things for me, so it felt nice to see things finally come together after working on it for a while.

I could see myself using these skills to build a personal portfolio. It's also nice to be self-reliant when it comes to skills like this. If I ever want to start my own business, it would be a real advantage to be able to build my own website, or at the very least, be able to communicate what I want to someone else.
